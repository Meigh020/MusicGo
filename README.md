# 🎵 MusicGo

Descargador de música web: pega un enlace, elige el formato y descarga.

## Formatos soportados

- 🔊 MP3
- 🎧 M4A
- 💎 FLAC (sin pérdida)
- ✨ OPUS (original, mejor calidad — sin recodificar)

## Estado del proyecto

🚧 En construcción — ver [PLAN.md](PLAN.md) para la arquitectura, el tutorial
de conceptos web y el plan por fases.

## Stack

- Backend: Python + FastAPI
- Descarga: yt-dlp
- Conversión: ffmpeg
- Frontend: React + Vite

## ⚠️ Uso responsable

Esta herramienta solo debe usarse con contenido propio, libre de derechos o con
permiso del autor. Respeta los términos de servicio de las plataformas y las
leyes locales de tu país.
